# Tic-Tac-Toe

## About

This Tic-Tac-Toe app is a live multiplayer app where you can compete in Tic-Tac-Toe with all of your friends!

## Technologies

The frontend is built in React and TypeScript, with Axios being used to call the backend. The backend is build with Express, TypeScript, Prisma, and Postgres. I have deployed it with Docker!!!

## Deployment

You can run a local instance using the docker-compose.yaml file.
